# 🌸 IrisLab – Iris Flower Classification

A beginner-friendly machine learning project with a small website. It classifies iris flowers into
three species (**Setosa, Versicolor, Virginica**) from the measurements of their sepals and petals.

**Skills gained:** numeric data analysis, classification modelling, evaluating results.

## Dataset
The classic Iris dataset (150 samples, 50 per species, 4 features in cm), bundled with `scikit-learn`
(`load_iris`). Also available from the UCI Machine Learning Repository. Measurements collected by
Edgar Anderson and made famous by R.A. Fisher (1936).

## What the project does
| Step | Done with |
|------|-----------|
| 1. Load the dataset | pandas, `load_iris` |
| 2. Explore visually (scatter plots, histograms, pair plot, correlation, ANOVA) | matplotlib / seaborn (script) and SVG charts (website) |
| 3. Split into training / test (80 / 20, stratified, seed 42) | `train_test_split` |
| 4. Preprocess (StandardScaler, fitted on training data only) | `StandardScaler` |
| 5. Train Logistic Regression, KNN, Decision Tree | scikit-learn |
| 6. Evaluate: accuracy, precision, recall, F1, confusion matrix, 5-fold cross-validation | scikit-learn metrics |

## How to run

```bash
# 1. (Optional) create a virtual environment
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3a. Run the ML script (prints results, saves plots in outputs/)
python iris_classification.py

# 3b. (Optional) regenerate the website data from scikit-learn
python export_data.py
```

### Open the website
No server or build step is needed. Just **double-click `frontend/index.html`**
(or open it in Chrome / Edge / Firefox).

The site shows every step with explanations and live charts, and has a **"Classify your own flower"**
section: move the sliders and the three trained models predict the species in your browser.
It also warns when your measurements are outside the range of the training data.

## How the website stays honest
- `export_data.py` runs scikit-learn and writes all results (statistics, split, metrics, confusion
  matrices, cross-validation, model parameters) into `frontend/data.js`.
- The charts are drawn from that data; no accuracy or chart is hardcoded.
- `model.js` re-implements prediction for the three *trained* models (scaler + coefficients, stored
  training flowers for KNN, tree thresholds). `node frontend/verify.js` confirms it matches scikit-learn.

## Results (random_state = 42)
| Model               | Test accuracy | Precision | Recall | F1    | 5-fold CV accuracy |
|---------------------|---------------|-----------|--------|-------|--------------------|
| Logistic Regression | 0.933         | 0.933     | 0.933  | 0.933 | 0.953 ± 0.045      |
| K-Nearest Neighbors | 0.933         | 0.944     | 0.933  | 0.933 | 0.973 ± 0.025      |
| Decision Tree       | 0.967         | 0.970     | 0.967  | 0.967 | 0.960 ± 0.025      |

**Observations**
- Setosa is perfectly separated from the other two species.
- Versicolor and Virginica overlap slightly, which causes the few mistakes.
- Petal length and petal width are the most useful features (highest ANOVA F-scores).
- The test set has only 30 flowers, so one mistake changes accuracy by about 3.3 points. The
  models are effectively tied; that's why cross-validation is reported too.
- Iris is small and well separated, so high scores are expected and do not transfer to harder
  real-world problems.

## Push to GitHub

1. Create a **new empty repository** on https://github.com/new (e.g. `iris-classification`).
   Do NOT add a README or .gitignore there.
2. In a terminal inside the project folder:

```bash
git init
git add .
git commit -m "Iris flower classification: ML script + website"
git branch -M main
git remote add origin https://github.com/<your-username>/iris-classification.git
git push -u origin main
```

Replace `<your-username>` with your GitHub username. If asked for a password, use a Personal Access
Token (GitHub → Settings → Developer settings → Personal access tokens), or use GitHub Desktop.

### (Optional) Put the website online with GitHub Pages
GitHub Pages can serve a folder called `docs`. Rename it and push:

```bash
git mv frontend docs
git commit -m "Publish website"
git push
```
Then on GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `docs` → Save.**
After a minute your site is live at `https://<your-username>.github.io/iris-classification/`.
(Update the paths in this README, and in `export_data.py` `OUT`, if you rename the folder.)
